# 求最低实付方案
$ node src/cli.js best --want "巨无霸,薯条,可乐"
全部单点基线 ¥50.00
最优解 ¥37.00 ← 巨无霸三件套，省 26%
看起来更省的 ¥59.50 ← 巨无霸四件套，菜单标 ¥32，其实是随单购价陷阱
菜单标 ¥32  →  官方核价 ¥59.50

「巨无霸四件套」那个 ¥32 是随单购麦金卡优惠价，不买卡根本拿不到。按标价排序会得出「四件套比三件套便宜」的错误结论——真实核价是贵 22.5 块。mcd-saver 对同一方案核两次价（常规价 + 随单购价），都给你看。

它解决四层肉眼算不清的信息差

价格全部来自官方核价接口，引擎自己不做任何优惠计算——所以陷阱会被自动暴露。

🍔

套餐 vs 单点

巨无霸+薯条+可乐单点 ¥50，巨无霸三件套只要 ¥37，省 26%。

🪤

随单购价陷阱

标价比三件套便宜 5 块，真付却贵 22.5 块。引擎两个价都核给你看。

🎟️

积分换哪张券

积分商城一次返回 24 张券，15 张已过期（官方不清理）。过滤后按「每 100 积分省多少」排序。

🔥

热量 / 饮食偏好

每个餐品标热量（套餐按成分累加），支持低脂 / 低糖 / 低钠 / 高蛋白 / 低卡排序与上限过滤。

三步跑起来

零第三方依赖，Node 18+ 用内置 fetch 直接跑。

# 1. 申请麦当劳 MCP Token（mcp.mcd.cn 控制台 → 激活） git clone https://github.com/zddamn/mcd-saver.git cd mcd-saver && export MCD_MCP_TOKEN=你的Token # 2. 求最低实付方案 node src/cli.js best --want "巨无霸,薯条,可乐" # 3. 更多玩法 node src/cli.js diet --diet low-fat # 低脂推荐 node src/cli.js points # 积分换哪张券最值 node src/cli.js report --want "巨无霸,薯条,可乐" --html report.html
🔒 隐私：Token 只存在你本地环境变量，项目不含任何真实凭证，配置仅含 ${MCD_MCP_TOKEN} 占位符。工具只做查询与核价，不自动下单、不自动领券（领券需显式 --bind）。所有价格来自官方 calculate-price。
